Lektion 9

HTML-Grundlagen

Jede Webseite, die du je gesehen hast, besteht aus HTML. Es ist keine Programmiersprache, sondern eine Beschreibung: Hier ist eine Überschrift, da ein Bild, dort ein Button.

Drei Sprachen, drei Aufgaben

Eine Webseite ist wie ein Haus:

  • HTML ist das Gerüst: Wände, Türen, Fenster. Was gibt es auf der Seite?
  • CSS ist die Einrichtung: Farben, Schriften, Abstände. Wie sieht es aus?
  • JavaScript ist die Elektrik: Licht an, Klingel, Rollläden. Was passiert, wenn man etwas tut?

Tags

HTML besteht aus Tags in spitzen Klammern. Die meisten kommen paarweise: ein öffnendes und ein schließendes Tag mit Schrägstrich. Was dazwischen steht, ist der Inhalt.

<h1>Das ist eine Überschrift</h1>
<p>Das ist ein Absatz.</p>

Öffnendes Tag, Inhalt und schließendes Tag zusammen nennt man ein Element.

Unten siehst du eine Spielwiese, ähnlich wie CodePen, ein Werkzeug, das auch Profis benutzen. Es gibt drei Felder: HTML, CSS und JS. Ändere im HTML-Feld etwas, die Vorschau darunter aktualisiert sich automatisch.

Attribute

Manche Tags brauchen Zusatzinfos. Die stehen als Attribute im öffnenden Tag, immer als name="wert":

<a href="https://de.wikipedia.org">Zur Wikipedia</a>
<img src="katze.jpg" alt="Eine schlafende Katze">

Das alt-Attribut beschreibt das Bild für Menschen, die es nicht sehen können, zum Beispiel weil sie blind sind und sich die Seite vorlesen lassen.

Das Grundgerüst

Eine vollständige HTML-Datei hat immer diesen Aufbau. Tags können ineinander stecken, wie Kisten in Kisten:

<!doctype html>
<html lang="de">
  <head>
    <meta charset="utf-8">
    <title>Steht im Browser-Tab</title>
  </head>
  <body>
    Alles, was man auf der Seite sieht, kommt hierhin.
  </body>
</html>

Der head enthält Infos über die Seite, der body den sichtbaren Inhalt. charset="utf-8" sorgt dafür, dass Umlaute wie ä, ö, ü richtig angezeigt werden.

In der Spielwiese schreibst du nur den Inhalt des body ins HTML-Feld, das Grundgerüst ergänzt sie automatisch. Klick auf „Als Datei speichern“, dann bekommst du die komplette HTML-Datei mit allem Drum und Dran. Die kannst du per Doppelklick im Browser öffnen oder in einem Texteditor anschauen.

Ein bisschen CSS

Mit CSS bestimmst du das Aussehen. In einer HTML-Datei steht es in einem <style>-Tag im head, in der Spielwiese kommt es einfach ins CSS-Feld. Zuerst sagst du, welche Elemente gemeint sind (der Selektor), dann in geschweiften Klammern, wie sie aussehen sollen:

h1 {
  color: purple;
  font-size: 40px;
}

Mit class kannst du einzelnen Elementen einen Namen geben und sie in CSS mit einem Punkt ansprechen: .highlight. Probier in der Spielwiese andere Farben (tomato, teal, #ff9900) und Größen aus.

Übung: Deine eigene Steckbrief-Seite

Bau eine Seite über dich (oder dein Haustier, deinen Lieblingsverein, ein Fantasiewesen …). Sie soll enthalten:

  • eine Überschrift <h1>
  • einen kurzen Absatz <p>
  • eine Liste mit mindestens drei Punkten
  • einen Link
  • mindestens zwei CSS-Regeln, zum Beispiel eine Hintergrundfarbe und eine Schriftfarbe

Diese Übung wird nicht automatisch geprüft. Zeig sie jemandem! Über „Im neuen Tab“ siehst du sie groß, über „Als Datei speichern“ kannst du sie behalten.

Tipp: Emojis sind einfach Zeichen. Du kannst sie direkt ins HTML schreiben, z. B. 🎮 🐱 ⚽. Am Mac mit Ctrl + ⌘ + Leertaste, unter Windows mit Windows-Taste + Punkt.
