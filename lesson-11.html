Lektion 11

Projekt: Zahlenraten

Zeit für dein erstes richtiges Spiel. Der Computer denkt sich eine Zahl zwischen 1 und 100 aus, du rätst. Nach jedem Tipp sagt er „zu hoch“ oder „zu niedrig“.

Erst planen, dann programmieren

Profis schreiben nicht einfach drauflos. Sie zerlegen ein Problem zuerst in kleine Schritte. Für unser Spiel:

  1. Eine geheime Zufallszahl zwischen 1 und 100 erzeugen.
  2. Ein Eingabefeld und einen Button „Raten“ anzeigen.
  3. Beim Klick die Eingabe lesen und in eine Zahl umwandeln.
  4. Vergleichen: zu hoch, zu niedrig oder richtig?
  5. Die Versuche zählen und anzeigen.
  6. Bei einem Treffer gratulieren und einen Neustart ermöglichen.

Alles davon kennst du schon, bis auf Schritt 1.

Zufallszahlen

Math.random() liefert eine zufällige Kommazahl zwischen 0 und 1 (zum Beispiel 0.7314…). Um daraus eine ganze Zahl von 1 bis 100 zu machen, sind drei Schritte nötig. Probier sie nacheinander aus und führ jede Zeile mehrmals aus:

Math.random() Math.random() * 100 Math.floor(Math.random() * 100) Math.floor(Math.random() * 100) + 1
  • * 100 macht daraus eine Zahl zwischen 0 und 99,999…
  • Math.floor schneidet die Nachkommastellen ab: 0 bis 99
  • + 1 verschiebt alles um eins: 1 bis 100

Übung: Würfel

Schreib eine Funktion rollDice(), die eine zufällige ganze Zahl von 1 bis 6 zurückgibt. Ich würfle damit tausendmal und schaue, ob alles passt.

Lösung anzeigen 
function rollDice() {
  return Math.floor(Math.random() * 6) + 1;
}

Das Spiel bauen

Hier ist das Gerüst. HTML und CSS sind fertig, im JS-Feld sind die Schritte als Kommentare vorbereitet. Füll die Lücken Schritt für Schritt und teste nach jedem Schritt. Mit console.log kannst du nachschauen, ob alles klappt. Die Ausgabe erscheint unter der Vorschau.

Komplette Lösung (JS) anzeigen 
const guessInput = document.querySelector("#guess");
const checkButton = document.querySelector("#check");
const feedback = document.querySelector("#feedback");
const attemptsDisplay = document.querySelector("#attempts");
const restartButton = document.querySelector("#restart");

let secretNumber = Math.floor(Math.random() * 100) + 1;
let attempts = 0;

checkButton.addEventListener("click", () => {
  const guess = Number(guessInput.value);

  attempts++;
  attemptsDisplay.textContent = `Versuche: ${attempts}`;

  if (guess > secretNumber) {
    feedback.textContent = "Zu hoch!";
  } else if (guess < secretNumber) {
    feedback.textContent = "Zu niedrig!";
  } else {
    feedback.textContent = `Richtig! 🎉 Die Zahl war ${secretNumber}.`;
    restartButton.style.display = "inline-block";
  }

  guessInput.value = "";
  guessInput.focus();
});

restartButton.addEventListener("click", () => {
  secretNumber = Math.floor(Math.random() * 100) + 1;
  attempts = 0;
  attemptsDisplay.textContent = "Versuche: 0";
  feedback.textContent = "";
  restartButton.style.display = "none";
});

Mach es zu deinem Spiel

Wenn es läuft, kannst du es erweitern. Such dir etwas aus:

  • Prüfe, ob die Eingabe wirklich zwischen 1 und 100 liegt, und zähle ungültige Versuche nicht mit.
  • Nach 7 Fehlversuchen ist das Spiel verloren.
  • Wechsle die Hintergrundfarbe: rot bei „zu hoch“, blau bei „zu niedrig“, grün bei „richtig“.
  • Raten auch mit Enter statt nur per Klick. Tipp: das Event "keydown" und event.key === "Enter".
  • Merke dir den Rekord (die wenigsten Versuche) in einer Variable und zeig ihn an.
  • Fertig? Mit „Als Datei speichern“ bekommst du dein Spiel als eigene HTML-Datei. Die kannst du verschicken oder auf einem USB-Stick mitnehmen.
