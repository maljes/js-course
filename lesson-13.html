Projekt: Quiz

Ein Quiz mit mehreren Fragen, Antwort-Buttons und einer Auswertung am Ende. Und weil du schon so viel gelernt hast, geht es in den Fragen um JavaScript selbst.

Der Plan

  1. Die Fragen als Daten speichern: ein Array aus Objekten.
  2. Eine Frage anzeigen und für jede Antwort einen Button erzeugen.
  3. Beim Klick prüfen, ob die Antwort stimmt, und das farbig zeigen.
  4. Mit „Weiter“ zur nächsten Frage.
  5. Am Ende die Punktzahl und eine passende Nachricht zeigen.

Das Spannende an diesem Projekt: Die Buttons stehen nicht fest im HTML. Jede Frage hat andere Antworten, also muss JavaScript die Buttons selbst bauen.

Fragen als Daten

Jede Frage ist ein Objekt mit drei Eigenschaften: dem Fragetext, einem Array mit Antworten und dem Index der richtigen Antwort. Alle Fragen zusammen stecken in einem Array.

const questions = [
  {
    question: "Welches Zeichen vergleicht zwei Werte?",
    answers: ["=", "===", "=>"],
    correct: 1,
  },
  {
    question: "Wie heißt die Liste in JavaScript?",
    answers: ["Array", "Objekt", "String"],
    correct: 0,
  },
];

correct: 1 heißt: Die zweite Antwort ist richtig, denn gezählt wird ab 0. Probier in der Konsole, wie du an die einzelnen Teile kommst:

const questions = [{ question: "Welches Zeichen vergleicht?", answers: ["=", "===", "=>"], correct: 1 }] questions[0].question questions[0].answers questions[0].answers[questions[0].correct]

Der große Vorteil: Wenn du eine neue Frage willst, fügst du nur ein Objekt hinzu. Am restlichen Code musst du nichts ändern.

Übung: Die Auswertung

Schreib resultMessage(score, total). Sie gibt je nach Ergebnis einen dieser Texte zurück:

  • alles richtig: Perfekt! 🏆
  • mindestens die Hälfte richtig: Gut gemacht! 👍
  • weniger als die Hälfte: Da geht noch was! 💪
Lösung anzeigen 
function resultMessage(score, total) {
  if (score === total) {
    return "Perfekt! 🏆";
  } else if (score >= total / 2) {
    return "Gut gemacht! 👍";
  }
  return "Da geht noch was! 💪";
}

Elemente mit JavaScript erzeugen

Bisher hast du nur Elemente verändert, die schon im HTML standen. Mit document.createElement baust du neue. Das passiert in drei Schritten:

  1. Element erzeugen: const item = document.createElement("li");
  2. Einrichten, zum Beispiel den Text setzen: item.textContent = "Neu!";
  3. In die Seite einhängen: list.append(item);

Erst mit Schritt 3 wird das Element sichtbar. Vorher existiert es nur im Speicher. Hier baut eine Schleife aus einem Array eine ganze Liste:

Füg im JS-Feld ein Essen zum Array hinzu. Die Liste wird automatisch länger. Mit list.textContent = "" wird ein Element komplett geleert. Das brauchst du gleich, um die Antworten der alten Frage zu entfernen.

Übung: Antwort-Button bauen

Schreib createAnswerButton(text). Sie erzeugt einen button, setzt den Text und gibt den Button zurück. Einhängen musst du ihn noch nicht.

Lösung anzeigen 
function createAnswerButton(text) {
  const button = document.createElement("button");
  button.textContent = text;
  return button;
}

Das Quiz bauen

Ein neuer Trick für dieses Projekt: Die Funktion showQuestion baut den kompletten Bereich der Frage jedes Mal neu auf, und zwar anhand von currentIndex, der Nummer der aktuellen Frage. Willst du zur nächsten Frage, erhöhst du einfach currentIndex und rufst showQuestion() erneut auf.

Beim Prüfen helfen dir zwei Dinge:

  • button.disabled = true macht einen Button unklickbar, damit man nicht zweimal antworten kann.
  • button.classList.add("correct") bzw. "wrong" färbt ihn grün oder rot. Die CSS-Regeln dafür sind schon da.
Komplette Lösung (JS ohne die Fragen) anzeigen 
let currentIndex = 0;
let score = 0;

function resultMessage(score, total) {
  if (score === total) {
    return "Perfekt! 🏆";
  } else if (score >= total / 2) {
    return "Gut gemacht! 👍";
  }
  return "Da geht noch was! 💪";
}

function createAnswerButton(text) {
  const button = document.createElement("button");
  button.textContent = text;
  return button;
}

function showQuestion() {
  const current = questions[currentIndex];
  progressDisplay.textContent = `Frage ${currentIndex + 1} von ${questions.length}`;
  questionDisplay.textContent = current.question;

  answersBox.textContent = "";
  nextButton.style.display = "none";

  for (let i = 0; i < current.answers.length; i++) {
    const button = createAnswerButton(current.answers[i]);
    button.addEventListener("click", () => {
      checkAnswer(i, button);
    });
    answersBox.append(button);
  }
}

function checkAnswer(index, button) {
  for (const answerButton of answersBox.querySelectorAll("button")) {
    answerButton.disabled = true;
  }

  if (index === questions[currentIndex].correct) {
    score++;
    button.classList.add("correct");
  } else {
    button.classList.add("wrong");
  }

  nextButton.style.display = "inline-block";
}

nextButton.addEventListener("click", () => {
  currentIndex++;
  if (currentIndex < questions.length) {
    showQuestion();
  } else {
    progressDisplay.textContent = `${score} von ${questions.length} richtig`;
    questionDisplay.textContent = resultMessage(score, questions.length);
    answersBox.textContent = "";
    nextButton.style.display = "none";
    restartButton.style.display = "inline-block";
  }
});

restartButton.addEventListener("click", () => {
  currentIndex = 0;
  score = 0;
  restartButton.style.display = "none";
  showQuestion();
});

showQuestion();

Mach es zu deinem Quiz

  • Schreib eigene Fragen: über dein Lieblingsspiel, deine Schule oder deine Freunde. Schick die gespeicherte Datei an jemanden und lass sie oder ihn raten.
  • Wenn die Antwort falsch war, färbe zusätzlich die richtige Antwort grün. Tipp: answersBox.querySelectorAll("button")[correct].
  • Zeig während des Spiels den Punktestand an.
  • Eine Zeitbegrenzung pro Frage. Dafür brauchst du setTimeout oder setInterval. Schlag sie auf MDN nach!
