Lektion 8

Objekte

Eine Spielfigur hat einen Namen, ein Level, Lebenspunkte und ein Inventar. Statt vier einzelner Variablen packst du alles in ein Objekt.

Ein Objekt anlegen

const player = {
  name: "Mia",
  level: 3,
  health: 100,
  items: ["Schwert", "Heiltrank"],
};

Ein Objekt steht in geschweiften Klammern. Darin stehen Paare aus Eigenschaft und Wert, getrennt durch einen Doppelpunkt. Die Werte können alles sein: Zahlen, Texte, Booleans, Arrays oder sogar weitere Objekte.

Eigenschaften lesen und ändern

Mit einem Punkt kommst du an eine Eigenschaft heran: player.level heißt „das Level des Spielers“.

const player = { name: "Mia", level: 3, health: 100, items: ["Schwert"] } player.name player.level++ player.health -= 30 player.items.push("Schild") player.coins = 50 player

Wie bei Arrays gilt: Auch ein const-Objekt kann man innen verändern. Neue Eigenschaften legst du einfach durch Zuweisen an, wie player.coins oben.

Funktionen im Objekt

Ein Objekt kann auch Funktionen enthalten. Sie heißen dann Methoden. Mit this meint die Methode „dieses Objekt hier“.

Jetzt weißt du auch, was console.log eigentlich ist: ein Objekt namens console mit einer Methode namens log!

Übung: Dein Profil als Objekt

Erstelle ein Objekt me mit den Eigenschaften name (Text), age (Zahl) und hobbies (Array mit mindestens zwei Texten). Gib danach dein erstes Hobby aus.

Lösung anzeigen 
const me = {
  name: "Sam",
  age: 14,
  hobbies: ["Fußball", "Zeichnen"],
};

console.log(me.hobbies[0]);

Übung: Inventar zählen

Jeder Gegenstand im Inventar hat eine Anzahl count. Schreib countItems(inventory), die zurückgibt, wie viele Gegenstände es insgesamt sind.

Lösung anzeigen 
function countItems(inventory) {
  let total = 0;
  for (const slot of inventory) {
    total += slot.count;
  }
  return total;
}
