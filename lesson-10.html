Lektion 10

JavaScript trifft HTML

Jetzt kommt alles zusammen. Mit JavaScript kannst du eine Webseite verändern, während man sie anschaut: Texte austauschen, Farben wechseln, auf Klicks reagieren.

Der Baum der Seite

Wenn der Browser HTML liest, baut er daraus einen Baum aus Objekten, das DOM (Document Object Model). Jedes Tag wird zu einem Objekt mit Eigenschaften, die du mit JavaScript lesen und ändern kannst. Der Einstieg ist das Objekt document.

Elemente finden

Mit document.querySelector(…) holst du dir ein Element. In die Klammern kommt ein Selektor, genau wie in CSS:

Selektorfindet
"h1"das erste <h1>
"#score"das Element mit id="score"
".card"das erste Element mit class="card"

Eine id ist wie ein Name, den es auf der Seite nur einmal geben darf. Dadurch findest du genau das richtige Element.

Elemente verändern

Ab jetzt benutzt du das JS-Feld der Spielwiese. Schau dir an, wie der Code im JS-Feld die Elemente aus dem HTML-Feld findet und verändert:

  • element.textContent = "…" ersetzt den Text.
  • element.style.color = "…" ändert CSS. Aus background-color wird in JavaScript backgroundColor.
  • element.classList.add("…") und .remove("…") fügen CSS-Klassen hinzu oder nehmen sie weg.

In einer echten HTML-Datei steht das <script> ganz unten im body. Warum? Der Browser liest von oben nach unten. Stünde das Skript oben, gäbe es das h1 noch gar nicht, und querySelector fände nichts (null). Die Spielwiese setzt dein JS automatisch an die richtige Stelle. Schau mal in die gespeicherte Datei!

Auf Klicks reagieren

Jetzt wird es interaktiv. Mit addEventListener sagst du einem Element: „Wenn das hier passiert, führe diese Funktion aus.“ So etwas nennt man ein Event.

Die Funktion () => { … } ist eine Pfeilfunktion ohne Namen. Sie wird nicht sofort ausgeführt, sondern erst, wenn jemand klickt. Deshalb sagt man auch Callback: Der Browser „ruft zurück“, wenn es so weit ist.

Eingaben lesen

Was jemand in ein <input> tippt, steht in .value. Denk an Lektion 3: Das ist immer ein Text! Für Zahlen brauchst du Number(…).

Übung: Zähler erweitern

Bau den Klickzähler von oben aus:

  1. Füge einen Button −1 hinzu, der den Zähler verringert.
  2. Füge einen Button Zurücksetzen hinzu, der auf 0 stellt.
  3. Bonus: Wenn der Zähler unter 0 ist, wird die Zahl rot, sonst schwarz.
Lösung anzeigen

HTML:

<p id="count">0</p>
<button id="minus">−1</button>
<button id="plus">+1</button>
<button id="reset">Zurücksetzen</button>

JS:

const countDisplay = document.querySelector("#count");
let count = 0;

function render() {
  countDisplay.textContent = count;
  countDisplay.style.color = count < 0 ? "red" : "black";
}

document.querySelector("#plus").addEventListener("click", () => {
  count++;
  render();
});
document.querySelector("#minus").addEventListener("click", () => {
  count--;
  render();
});
document.querySelector("#reset").addEventListener("click", () => {
  count = 0;
  render();
});

Die Funktion render verhindert, dass man denselben Code dreimal schreibt. bedingung ? a : b ist eine Kurzform für if/else: „Wenn die Bedingung stimmt, nimm a, sonst b.“

Übung: Taschenrechner für zwei Zahlen

Beim Klick auf „Addieren“ soll die Summe der beiden Zahlen darunter erscheinen. Teste mit 2 und 3. Kommt 5 raus oder 23? Wenn 23: Woran liegt's?

Lösung anzeigen 
const first = document.querySelector("#first");
const second = document.querySelector("#second");
const result = document.querySelector("#result");

document.querySelector("#add").addEventListener("click", () => {
  const sum = Number(first.value) + Number(second.value);
  result.textContent = `Ergebnis: ${sum}`;
});
