Lektion 2

Variablen

Ein Spiel muss sich merken, wie viele Punkte du hast. Eine App merkt sich deinen Namen. Dafür gibt es Variablen.

Eine Kiste mit Etikett

Stell dir eine Variable wie eine Kiste vor, auf der ein Name steht. In die Kiste legst du einen Wert. Später kannst du über den Namen wieder an den Wert kommen.

let score = 0;
let playerName = "Mia";

Das liest man so: „Erstelle (let) eine Kiste namens score und lege 0 hinein.“ Das = heißt hier nicht „ist gleich“ wie in Mathe, sondern „bekommt den Wert“.

let score = 0 score score = score + 10 score + 5

Merke: let nur beim ersten Mal! Danach benutzt du einfach den Namen. Wenn du let zweimal für denselben Namen schreibst, meckert JavaScript, probier es ruhig aus.

Werte verändern

Weil Punkte ständig hoch- und runtergehen, gibt es Abkürzungen:

LangKurz
score = score + 10score += 10
score = score - 5score -= 5
score = score + 1score++

let oder const?

Manche Werte ändern sich nie, zum Beispiel die Anzahl der Tage pro Woche. Dafür nimmst du const (von englisch constant, unveränderlich):

const daysPerWeek = 7;
daysPerWeek = 8;   // Fehler! const kann man nicht ändern.

Faustregel: Nimm const, wenn sich der Wert nicht ändern soll, sonst let.

Gute Namen

  • Keine Leerzeichen. Mehrere Wörter schreibt man zusammen, jedes neue Wort groß: highScore, playerName. Das heißt camelCase, weil die Großbuchstaben wie Kamelhöcker aussehen.
  • Groß- und Kleinschreibung zählt: score und Score sind zwei verschiedene Kisten.
  • Der Name soll sagen, was drin ist. lives ist besser als x.
  • Profis schreiben Namen im Code auf Englisch, damit Menschen auf der ganzen Welt ihn verstehen. Das machen wir hier auch. Texte, die der Nutzer sieht, bleiben natürlich deutsch.

Texte zusammenbauen

Variablen kannst du mit Text verbinden. Es gibt zwei Wege:

const name = "Mia";
const age = 13;

// 1. Mit +
console.log("Ich heiße " + name + " und bin " + age + " Jahre alt.");

// 2. Mit Backticks ` und ${…} – übersichtlicher!
console.log(`Ich heiße ${name} und bin ${age} Jahre alt.`);

Die Backticks ` findest du auf der deutschen Tastatur rechts neben dem ß (mit Shift, danach Leertaste). Alles in ${…} wird durch den Wert ersetzt. Das nennt man Template-String.

Übung: Steckbrief

Erstelle eine Variable name mit deinem Namen (Text) und eine Variable age mit deinem Alter (Zahl, ohne Anführungszeichen). Gib dann einen Satz aus, in dem beide vorkommen.

Lösung anzeigen 
const name = "Sam";
const age = 14;
console.log(`Ich heiße ${name} und bin ${age} Jahre alt.`);

Übung: Punktestand

Ein Spieler sammelt dreimal 10 Punkte und verliert dann 5 Punkte. Ändere score Schritt für Schritt (nicht einfach 25 hinschreiben!) und gib am Ende den Punktestand aus.

Lösung anzeigen 
let score = 0;
score += 10;
score += 10;
score += 10;
score -= 5;
console.log(score);
