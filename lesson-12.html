Lektion 12

Projekt: Schere, Stein, Papier

Du gegen den Computer. Schere schneidet Papier, Papier wickelt Stein ein, Stein macht die Schere stumpf. Wer gewinnt öfter?

Der Plan

  1. Der Computer wählt zufällig Schere, Stein oder Papier.
  2. Eine Funktion entscheidet, wer gewonnen hat.
  3. Drei Buttons, einer pro Wahl.
  4. Nach jeder Runde: beide Wahlen anzeigen, Sieger nennen, Punktestand erhöhen.

Diesmal baust du zuerst die Logik, also die Regeln des Spiels, ganz ohne HTML. Erst wenn sie stimmt, kommt die Oberfläche dazu. So machen es auch Profis: Logik lässt sich viel leichter testen als Buttons.

Zufällig aus einer Liste wählen

In Lektion 11 hast du eine Zufallszahl erzeugt. Damit kannst du auch einen zufälligen Eintrag aus einem Array holen: Du erzeugst einen zufälligen Index von 0 bis length - 1.

const snacks = ["Chips", "Apfel", "Popcorn", "Gummibärchen"] Math.floor(Math.random() * snacks.length) snacks[Math.floor(Math.random() * snacks.length)]

Weil Math.floor(Math.random() * 4) nur 0, 1, 2 oder 3 ergibt, passt der Index immer. Und das Schöne: Wenn du einen Snack hinzufügst, funktioniert der Code ohne Änderung weiter.

Im Code verwenden wir englische Bezeichnungen: "rock" (Stein), "paper" (Papier) und "scissors" (Schere). Was der Spieler sieht, bleibt natürlich deutsch. Dazu gleich mehr.

Übung: Der Computer wählt

Schreib randomChoice(), die zufällig "rock", "paper" oder "scissors" zurückgibt. Benutze das Array choices.

Lösung anzeigen 
function randomChoice() {
  const index = Math.floor(Math.random() * choices.length);
  return choices[index];
}

Wer gewinnt?

Das ist das Herzstück. Es gibt drei mögliche Ergebnisse: Unentschieden, der Spieler gewinnt, oder der Computer gewinnt. Statt alle neun Kombinationen einzeln aufzuschreiben, kannst du clever vorgehen:

  1. Sind beide Wahlen gleich? Dann unentschieden.
  2. Gehört die Kombination zu den drei Fällen, in denen der Spieler gewinnt? Dann Spieler.
  3. Sonst hat der Computer gewonnen.

Übung: Der Schiedsrichter

Schreib getWinner(player, computer). Sie gibt "draw" (unentschieden), "player" oder "computer" zurück. Ich teste alle neun Kombinationen.

Tipp anzeigen

Der Spieler gewinnt in genau diesen drei Fällen. Verbinde sie mit ||:

  • player === "rock" && computer === "scissors"
  • player === "paper" && computer === "rock"
  • player === "scissors" && computer === "paper"
Lösung anzeigen 
function getWinner(player, computer) {
  if (player === computer) {
    return "draw";
  }
  if (
    (player === "rock" && computer === "scissors") ||
    (player === "paper" && computer === "rock") ||
    (player === "scissors" && computer === "paper")
  ) {
    return "player";
  }
  return "computer";
}

Ein Objekt als Übersetzer

Der Spieler soll natürlich nicht „scissors“ lesen, sondern „Schere ✌️“. Dafür eignet sich ein Objekt wie ein Wörterbuch: Die Eigenschaften sind die englischen Namen, die Werte das, was angezeigt wird.

const labels = {
  rock: "Stein ✊",
  paper: "Papier ✋",
  scissors: "Schere ✌️",
};

const choice = "paper";
console.log(labels[choice]); // "Papier ✋"

Neu ist die Schreibweise mit eckigen Klammern: labels[choice]. Sie brauchst du, wenn der Name der Eigenschaft in einer Variable steckt. labels.choice würde nach einer Eigenschaft suchen, die wörtlich „choice“ heißt, und die gibt es nicht.

Mehrere Buttons, ein Code

Für drei Buttons dreimal fast denselben Code zu schreiben, wäre mühsam. Besser: Jeder Button bekommt ein data-Attribut mit seiner Wahl. Mit document.querySelectorAll holst du dir alle auf einmal und gibst ihnen in einer Schleife denselben Klick-Code:

<button data-choice="rock">Stein ✊</button>
<button data-choice="paper">Papier ✋</button>
const buttons = document.querySelectorAll("[data-choice]");

for (const button of buttons) {
  button.addEventListener("click", () => {
    console.log(button.dataset.choice); // "rock" oder "paper"
  });
}

Aus data-choice im HTML wird in JavaScript button.dataset.choice. Probier es in der Spielwiese aus und schau dir die Konsole an.

Das Spiel bauen

HTML und CSS sind fertig. Kopier deine beiden Funktionen von oben ins JS-Feld und füll dann die Lücken.

Komplette Lösung (JS) anzeigen 
const roundDisplay = document.querySelector("#round");
const resultDisplay = document.querySelector("#result");
const scoreDisplay = document.querySelector("#score");

const choices = ["rock", "paper", "scissors"];
const labels = {
  rock: "Stein ✊",
  paper: "Papier ✋",
  scissors: "Schere ✌️",
};

const score = { player: 0, computer: 0 };

function randomChoice() {
  return choices[Math.floor(Math.random() * choices.length)];
}

function getWinner(player, computer) {
  if (player === computer) {
    return "draw";
  }
  if (
    (player === "rock" && computer === "scissors") ||
    (player === "paper" && computer === "rock") ||
    (player === "scissors" && computer === "paper")
  ) {
    return "player";
  }
  return "computer";
}

function playRound(playerChoice) {
  const computerChoice = randomChoice();
  roundDisplay.textContent = `Du: ${labels[playerChoice]} – Computer: ${labels[computerChoice]}`;

  const winner = getWinner(playerChoice, computerChoice);
  if (winner === "player") {
    score.player++;
    resultDisplay.textContent = "Gewonnen! 🎉";
  } else if (winner === "computer") {
    score.computer++;
    resultDisplay.textContent = "Verloren 😢";
  } else {
    resultDisplay.textContent = "Unentschieden";
  }

  scoreDisplay.textContent = `Du ${score.player} : ${score.computer} Computer`;
}

for (const button of document.querySelectorAll("[data-choice]")) {
  button.addEventListener("click", () => {
    playRound(button.dataset.choice);
  });
}

Mach es zu deinem Spiel

  • Wer zuerst 3 Punkte hat, gewinnt das ganze Match. Danach gibt es einen Button „Neues Match“.
  • Färbe resultDisplay grün, rot oder grau, je nach Ergebnis.
  • Zähle mit, wie oft du schon welche Wahl getroffen hast. Ein Objekt wie { rock: 0, paper: 0, scissors: 0 } hilft.
  • Schwer: Erweitere das Spiel um Echse und Spock (aus „The Big Bang Theory“). Wie musst du getWinner ändern? Gibt es einen Weg, die Regeln in einem Objekt zu speichern statt in vielen ||?
