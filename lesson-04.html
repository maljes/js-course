Entscheidungen mit if

Bisher laufen deine Programme stur von oben nach unten. Jetzt lernen sie, auf Situationen zu reagieren: Wenn das Leben auf 0 fällt, ist das Spiel vorbei.

Wenn … dann …

if (lives === 0) {
  console.log("Game Over");
}

So liest man das: „Wenn (if) die Bedingung in den runden Klammern true ist, dann führe aus, was in den geschweiften Klammern { } steht.“ Ist sie false, wird der Block einfach übersprungen.

Die geschweiften Klammern bekommst du mit Alt Gr + 7 und 0 (am Mac ⌥ + 8 und 9).

… sonst …

Mit else sagst du, was passieren soll, wenn die Bedingung nicht stimmt. Mit else if kannst du beliebig viele Fälle nacheinander prüfen. Der erste passende gewinnt, der Rest wird übersprungen.

Ändere temperature auf 30, 10 und -2 und führe das Programm jedes Mal aus. Welche Zeile wird ausgegeben?

Der Code zwischen den { } ist eingerückt, also mit zwei Leerzeichen nach rechts geschoben. Dem Computer ist das egal, aber Menschen sehen so sofort, was zusammengehört. Der Editor rückt automatisch ein, wenn du nach { Enter drückst.

Mehrere Bedingungen

Die Zeichen && und || aus Lektion 3 funktionieren natürlich auch in if:

if (hasTicket && age >= 16) {
  console.log("Viel Spaß im Konzert!");
}

Fragen stellen mit prompt

Mit prompt("Frage") öffnet der Browser ein kleines Fenster, in das man etwas eintippen kann. Die Antwort ist immer ein Text.

Übung: Notenrechner

In einem Test gibt es maximal 100 Punkte. Gib je nach points genau eine dieser Zeilen aus:

  • ab 90 Punkten: sehr gut
  • ab 75 Punkten: gut
  • ab 50 Punkten: bestanden
  • darunter: nicht bestanden

Ich teste dein Programm mit vielen verschiedenen Punktzahlen.

Lösung anzeigen 
let points = 73;

if (points >= 90) {
  console.log("sehr gut");
} else if (points >= 75) {
  console.log("gut");
} else if (points >= 50) {
  console.log("bestanden");
} else {
  console.log("nicht bestanden");
}

Die Reihenfolge ist wichtig: Würdest du zuerst points >= 50 prüfen, bekäme auch jemand mit 95 Punkten nur „bestanden“.

Übung: Gerade oder ungerade?

Gib für number aus, ob sie gerade oder ungerade ist. Tipp: Gerade Zahlen haben beim Teilen durch 2 keinen Rest. Erinnerst du dich an %?

Lösung anzeigen 
if (number % 2 === 0) {
  console.log("gerade");
} else {
  console.log("ungerade");
}
