Arrays (Listen)

Eine Playlist, die Highscore-Tabelle, dein Inventar im Spiel: Ständig hat man es mit Listen zu tun. In JavaScript heißen sie Arrays.

Eine Liste anlegen

const games = ["Minecraft", "Mario Kart", "Zelda"];
const scores = [120, 85, 300, 42];

Ein Array steht in eckigen Klammern [ ], die Einträge werden durch Kommas getrennt. Die eckigen Klammern bekommst du mit Alt Gr + 8 und 9 (am Mac ⌥ + 5 und 6).

Werte zusammenzählen

Ein typisches Muster: Du startest mit einer Variable bei 0 und addierst in der Schleife jeden Eintrag dazu.

const coins = [5, 10, 3];
let total = 0;
for (const amount of coins) {
  total += amount;
}
console.log(total); // 18

Übung: Summe

Schreib eine Funktion sum(numbers), die alle Zahlen eines Arrays zusammenzählt und das Ergebnis zurückgibt. Für eine leere Liste [] soll 0 herauskommen.

Lösung anzeigen 
function sum(numbers) {
  let total = 0;
  for (const number of numbers) {
    total += number;
  }
  return total;
}

Übung: Highscore

Schreib highest(scores), die die größte Zahl der Liste zurückgibt. Löse es mit einer Schleife: Merk dir den bisher größten Wert und vergleiche jeden Eintrag damit.

Lösung anzeigen 
function highest(scores) {
  let best = scores[0];
  for (const score of scores) {
    if (score > best) {
      best = score;
    }
  }
  return best;
}

Warum startet best mit scores[0] und nicht mit 0? Überleg mal, was bei [-5, -2, -9] passieren würde.

Übung: Nur die Bestandenen

Schreib passed(scores), die ein neues Array zurückgibt, in dem nur die Werte ab 50 stehen. Tipp: Starte mit einer leeren Liste [] und benutze push.

Lösung anzeigen 
function passed(scores) {
  const result = [];
  for (const score of scores) {
    if (score >= 50) {
      result.push(score);
    }
  }
  return result;
}
