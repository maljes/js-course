Lektion 6

Funktionen

Eine Funktion ist ein eigener Befehl, den du einmal baust und dann so oft benutzt, wie du willst. Du kennst schon welche: console.log, prompt und Number sind Funktionen.

Eine Funktion bauen

function greet() {
  console.log("Hallo!");
  console.log("Schön, dass du da bist.");
}

greet();   // ruft die Funktion auf
greet();   // und gleich nochmal

Mit function legst du fest, was die Funktion tut. Dabei passiert noch nichts! Erst der Aufruf mit Namen und runden Klammern, also greet(), führt den Code aus.

Parameter: Werte mitgeben

Richtig nützlich werden Funktionen, wenn man ihnen etwas mitgeben kann. In den runden Klammern stehen Parameter, das sind Variablen, die beim Aufruf einen Wert bekommen:

return: ein Ergebnis zurückgeben

Viele Funktionen berechnen etwas und geben das Ergebnis mit return zurück. Den Rückgabewert kannst du dann in einer Variable speichern oder weiterverwenden:

Der Unterschied ist wichtig: console.log zeigt etwas an, return gibt etwas zurück. Mit einem angezeigten Wert kann dein Programm nicht weiterrechnen, mit einem zurückgegebenen schon.

Nach return ist die Funktion sofort beendet. Code dahinter wird nicht mehr ausgeführt.

Kurzschreibweise: Pfeilfunktionen

In modernem JavaScript siehst du oft diese kürzere Schreibweise. Sie macht genau das Gleiche:

const square = (number) => number * number;

Du musst sie noch nicht selbst benutzen, aber erkennen solltest du sie.

In der Konsole testen

Funktionen kann man prima in der Konsole ausprobieren. Gib die erste Zeile ein und ruf die Funktion dann mit verschiedenen Werten auf:

function triple(x) { return x * 3; } triple(4) triple(triple(2)) triple("ha")

Übung: Verdoppeln

Schreib eine Funktion double(number), die die Zahl verdoppelt und mit return zurückgibt.

Lösung anzeigen 
function double(number) {
  return number * 2;
}

Übung: Celsius in Fahrenheit

In den USA misst man Temperatur in Fahrenheit. Die Formel lautet: Celsius mal 9, geteilt durch 5, plus 32. Schreib toFahrenheit(celsius).

Lösung anzeigen 
function toFahrenheit(celsius) {
  return celsius * 9 / 5 + 32;
}

Übung: Ist die Zahl gerade?

Schreib isEven(number), die true zurückgibt, wenn die Zahl gerade ist, sonst false. Profi-Tipp: Ein Vergleich ergibt schon true oder false. Du brauchst nicht unbedingt ein if.

Lösung anzeigen 
function isEven(number) {
  return number % 2 === 0;
}
