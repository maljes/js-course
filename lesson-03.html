Datentypen & Vergleiche

Nicht jeder Wert ist gleich. Eine Zahl kann man teilen, einen Text nicht. Und manchmal braucht man nur eine Antwort: ja oder nein.

Die drei wichtigsten Typen

TypWas ist das?Beispiele
numberZahlen, ganz oder mit Komma42, -3, 9.99
stringText in Anführungszeichen"Hallo", "42"
booleanWahrheitswert: nur zwei Möglichkeitentrue (wahr), false (falsch)

Mit typeof fragst du JavaScript, welcher Typ ein Wert ist:

typeof 42 typeof "42" typeof true typeof undefined

Die große Falle: "5" + 3

Was kommt bei "5" + 3 raus? Probier es aus, bevor du weiterliest.

"5" + 3 5 + 3 Number("5") + 3 "5" * 3

Weil "5" ein Text ist, hängt + die beiden einfach aneinander: "53". Mit Number(…) wandelst du einen Text in eine Zahl um. Das wird später wichtig, denn alles, was jemand in ein Eingabefeld tippt, ist erst mal ein Text.

Vergleichen

Vergleiche ergeben immer einen Boolean, also true oder false:

ZeichenFrageBeispiel
===Ist gleich?3 === 3 → true
!==Ist ungleich?3 !== 4 → true
< / >Kleiner / größer?2 < 5 → true
<= / >=Kleiner gleich / größer gleich?5 >= 5 → true

Ein = gibt einer Variable einen Wert. Drei === vergleichen. Das verwechselt jeder mal!

Es gibt auch == mit nur zwei Zeichen. Das ist aber tückisch, weil es Typen heimlich umwandelt: "5" == 5 ist true. Nimm immer ===.

10 > 3 "Mia" === "mia" "5" === 5 let age = 13 age >= 12

Und, oder, nicht

Oft hängen Entscheidungen von mehreren Dingen ab. „Ich gehe raus, wenn es warm ist und nicht regnet.“

ZeichenBedeutungWann true?
&&undwenn beide Seiten true sind
||oderwenn mindestens eine Seite true ist
!nichtdreht den Wert um: !true ist false

Den senkrechten Strich | bekommst du auf der deutschen Tastatur mit Alt Gr + < (am Mac ⌥ + 7).

Übung: Achterbahn

Auf die Achterbahn darf, wer mindestens 12 Jahre alt und mindestens 140 cm groß ist. Berechne canRide aus age und height und gib es aus. Ich teste deine Lösung danach auch mit anderen Werten.
