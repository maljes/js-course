Schleifen

Schreib 100-mal „Ich soll im Unterricht nicht schwatzen“. Mit der Hand eine Strafe, mit JavaScript drei Zeilen. Computer lieben Wiederholungen.

Die for-Schleife

Die runden Klammern haben drei Teile, getrennt durch ;:

TeilBedeutung
let i = 1Start: Ein Zähler namens i beginnt bei 1. Das passiert nur einmal.
i <= 5Bedingung: Vor jeder Runde wird geprüft: Ist sie noch true? Dann geht's weiter, sonst ist Schluss.
i++Schritt: Nach jeder Runde wird i um 1 erhöht.

Ändere das Programm so, dass es bis 100 zählt. Dann so, dass es nur gerade Zahlen ausgibt. Tipp: i += 2.

Schleifen und if zusammen

Innerhalb einer Schleife kannst du alles benutzen, was du schon kennst. Hier werden nur die Zahlen ausgegeben, die durch 3 teilbar sind:

for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) {
    console.log(i);
  }
}

Übung: Countdown

Zähle von 10 rückwärts bis 1 und gib danach Start! aus. Tipp: Der Zähler startet bei 10 und wird mit i-- kleiner.

Lösung anzeigen 
for (let i = 10; i >= 1; i--) {
  console.log(i);
}
console.log("Start!");

Übung: Das Einmaleins der 7

Gib die Siebenerreihe aus, genau in diesem Format:

1 x 7 = 7
2 x 7 = 14
…
10 x 7 = 70
Lösung anzeigen 
for (let i = 1; i <= 10; i++) {
  console.log(`${i} x 7 = ${i * 7}`);
}

Bonus: FizzBuzz

Ein Klassiker, der sogar in Bewerbungsgesprächen für Programmierer gefragt wird. Gib die Zahlen von 1 bis 30 aus, aber:

  • statt Zahlen, die durch 3 teilbar sind: Fizz
  • statt Zahlen, die durch 5 teilbar sind: Buzz
  • statt Zahlen, die durch 3 und 5 teilbar sind: FizzBuzz
Lösung anzeigen 
for (let i = 1; i <= 30; i++) {
  if (i % 15 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}

Der Trick: Den Fall „durch 3 und 5“ (also durch 15) musst du zuerst prüfen.
